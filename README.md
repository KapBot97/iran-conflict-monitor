# Iran Conflict Monitor

Interactive map and intelligence dashboard tracking the 2026 Iran war.

## Features
- Real-time conflict event mapping (airstrikes, missile attacks)
- Energy infrastructure risk overlay (oil, LNG, helium, nuclear)
- Strait of Hormuz shipping status
- Missile range visualization from Tehran
- Timeline filtering
- Bloomberg-terminal dark aesthetic

## Live Map
Visit: https://kapbot97.github.io/iran-conflict-monitor/map/
